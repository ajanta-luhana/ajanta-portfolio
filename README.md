# Ajanta Luhana — Portfolio

Static site (HTML + CSS + JS, Three.js from CDN). Works on GitHub Pages.

## Files
- `index.html` — page structure
- `css/style.css` — design
- `js/data.js` — ALL content (projects, experience, skills, certificates). Edit here only.
- `js/neural.js` — 3D neural-network hero
- `js/main.js` — rendering and interactions
- `assets/profile.jpg` — put your LinkedIn profile photo here (square, ~600×600). Initials "AL" show until then.
- `Ajanta_Luhana_Resume.pdf` — keep your existing resume in the repo root.

## Deploy
Copy everything into the repo root (replace old `index.html` and `js/`), commit, push.
GitHub → Settings → Pages → Deploy from branch `main` / root.
